# Georgian rank insignia icons

19 icons modelled on the Georgian Defence Forces insignia (ka.wikipedia «საქართველოს სამხედრო წოდებები»), highest (01) to lowest (19).

- `svg/` vector files, 80×110 viewBox. Use these in the Angular app.
- `png/` 440 px tall PNGs.
- `ranks.json` file, Georgian name, English name, NATO code.

Angular: copy `svg/` to `public/ranks/` and use
`<img src="ranks/08-of-2-captain.svg" alt="კაპიტანი" height="40">`

Note: General of the Army (01) was not in the reference images; it follows the general-officer pattern with 4 stars.
These are redrawn look-alikes, not the official artwork files.
